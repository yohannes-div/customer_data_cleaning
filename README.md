Customer Data Cleaning and Preparation Using Python

Project Overview

This project demonstrates how to clean and prepare customer data using Python and Pandas.

Objectives

Remove duplicate records.

Handle missing values.

Standardize customer names.

Clean email addresses.

Standardize city names.

Prepare a clean dataset for analysis.

Tools and Technologies

Python

Pandas

Google Colab

Jupyter Notebook

Data Cleaning Process

Created a customer dataset.

Removed duplicate records.

Handled missing names, emails, and ages.

Standardized text formatting.

Checked missing values after cleaning.

Exported the cleaned dataset to CSV.

Project Files

cleand_customer_data_csv.ipynb – Python notebook.

cleaned_customer_data.csv – Cleaned dataset.

Results

The original dataset contained six records. After removing one duplicate record and handling missing values, five cleaned records remained.

Conclusion

This project demonstrates beginner-level practical skills in data cleaning, data preparation, and Python programming using Pandas.
